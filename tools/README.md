# 스마트스토어 상품명 수집기

네이버 스마트스토어 카테고리를 첫 쪽부터 끝까지 넘겨가며 **상품명만** 뽑아
메모장에서 바로 열 수 있는 텍스트 파일로 저장하는 프로그램입니다.

```
체인소 맨 1~23권 세트 / 후지모토 타츠키
원피스 1~110권 세트 / 오다 에이이치로
...
```

가격(`138,000원`), 할인율(`10%`), `무료배송`, 연령 배지(`19`), 리뷰 수 같은
부가 텍스트는 걸러내고 상품명 한 줄씩만 남깁니다.

## 구성

| 파일 | 설명 |
| --- | --- |
| `smartstore_gui.py` | **GUI 프로그램** (창을 띄워 마우스로 조작) |
| `smartstore_cli.py` | 명령줄 버전 (자동화용) |
| `smartstore_core.py` | 수집 로직 (위 두 개가 공통으로 사용) |
| `RUN.bat` | 윈도우에서 더블클릭으로 GUI 실행 |
| `launcher.py` | RUN.bat 이 부르는 준비·실행 스크립트 (첫 실행 때 준비물 자동 설치) |
| `build_exe.bat` | 윈도우에서 단독 실행 파일(.exe) 만들기 |
| `build_exe.sh` | 리눅스·맥에서 단독 실행 파일 만들기 |
| `requirements.txt` | 필요한 패키지 |

## 설치 (처음 한 번만)

[Python 3.9 이상](https://www.python.org/downloads/)을 설치한 뒤, 명령
프롬프트에서:

```bash
pip install -r requirements.txt
playwright install chromium
```

> 카테고리 페이지는 자바스크립트로 그려지기 때문에, 진짜 브라우저로 화면을
> 띄워 읽어야 상품명이 나옵니다. 그래서 Chromium이 필요합니다.

## 실행

### GUI (권장)

윈도우에서는 `RUN.bat` 을 더블클릭하고, 그 외에는:

```bash
python smartstore_gui.py
```

1. **카테고리 주소**에 수집할 카테고리 URL을 붙여넣습니다.
   (주소에 `?cp=2` 같은 페이지 번호가 붙어 있어도 무시하고 1쪽부터 전체를 훑습니다.)
2. **저장할 파일**을 정합니다. 기본값은 `상품명.txt` 입니다.
3. **[수집 시작]** 을 누릅니다. 진행 상황이 아래 창에 실시간으로 찍힙니다.
4. 끝나면 **[저장한 파일 열기]** 로 메모장에서 바로 확인합니다.

수집 도중 **[중지]** 를 누르면 그때까지 모은 상품명까지만 저장합니다.

옵션:

| 옵션 | 설명 |
| --- | --- |
| 최대 페이지 | 안전장치. 이 페이지 수를 넘으면 멈춥니다 (기본 100) |
| 페이지 간 대기 | 서버에 부담을 주지 않도록 쉬는 시간 (기본 1초) |
| 브라우저 창 보기 | 실제 크롬 창을 띄움 (기본 켜짐) |
| 방문 기록 유지 | 쿠키를 남겨 재방문자처럼 보이게 함 (기본 켜짐) |
| 설치된 크롬 사용 | PC에 깔린 크롬으로 실행, 없으면 자동 폴백 (기본 켜짐) |

### 네이버 로그인 화면으로 튕길 때

네이버는 자동화된 브라우저를 걸러내 `nid.naver.com` 로그인 화면으로 돌려보냅니다.
로그인이 필요한 페이지라서가 아니라 — 같은 주소를 평소 쓰던 크롬에서 열면
로그인 없이 보입니다.

이를 줄이려고 프로그램은 자동화 표식을 남기지 않는 방향으로 브라우저를 엽니다.

- `--disable-blink-features=AutomationControlled` 로 `navigator.webdriver` 를 없앰
- 헤드리스일 때만 User-Agent 에서 `HeadlessChrome` 를 제거 (창을 띄우면 원래 없음)
- 로케일 `ko-KR`, 시간대 `Asia/Seoul`, 일반적인 뷰포트와 `Accept-Language`
- 프로필 폴더로 쿠키를 남겨 재방문자처럼 보이게
- 가능하면 PC에 설치된 진짜 크롬 사용
- 크롬 샌드박스를 켠 상태로 실행 (Playwright 기본값은 꺼짐이라 크롬에
  "지원되지 않는 명령줄 플래그" 경고 띠가 뜨고, 그것도 구별되는 표시가 된다)
- 카테고리 주소로 곧장 뛰어들지 않고 **스토어 첫 화면을 먼저 방문**한 뒤
  들어감 (사람이 실제로 이동하는 순서라 쿠키와 referer 가 갖춰진다)

### 카테고리 딥링크는 쓰지 않는다

`smartstore.naver.com/{스토어}/category/{해시}` 형태의 주소는 **로그인 세션이
없으면 열리지 않습니다.** 시크릿 창에 붙여넣어도 로그인 화면으로 튕깁니다.
반면 스토어 첫 주소 `smartstore.naver.com/{스토어}` 는 로그인 없이 열립니다.

그래서 프로그램은 **스토어 첫 화면에서 메뉴를 눌러** 카테고리로 들어갑니다.
사람이 실제로 이동하는 경로라 세션이 갖춰진 채로 넘어갑니다.

- **스토어 주소**: `https://smartstore.naver.com/yes24book`
- **카테고리 메뉴**: `국내도서` (첫 화면 상단 메뉴에 보이는 글자 그대로)

메뉴 이름을 비우면 입력한 주소를 그대로 엽니다.

### 19 표시 상품만 모으기

`adult_only` 를 켜면 상품 이미지 자리에 19 배지가 붙은 상품만 모읍니다.

판별은 상품 카드의 **배지와 이미지**만 보고, 상품명은 보지 않습니다. 제목에
`19` 가 들어간 일반 도서(`1919년 독립운동사` 등)가 딸려오지 않게 하기 위함입니다.
단서는 여러 갈래를 함께 봅니다.

- 카드 안의 짧은 글자가 `19` / `19세` / `19금` / `성인`
- `19세 이상`, `성인 인증`, `청소년 유해`, `adult` 가 들어간 문구나 이미지 설명
- 이미지 주소에 `adult`, `19over`, `age19` 등이 들어간 경우

실제 네이버 화면의 표시 방식은 확인하지 못했으므로, 결과가 0개로 나오면
`debug_dump` 로 첫 쪽 카드 HTML 을 남겨 실제 구조에 맞추면 됩니다.

그래도 로그인 화면이 뜨면, 창을 띄운 상태에서는 프로그램이 최대 5분간 기다립니다.
사용자가 뒤로 가기로 원래 주소에 돌아오면 수집을 이어갑니다.

**로그인은 권하지 않습니다.** 로그인하면 19세 상품의 표시가 달라져 화면에 보이는
내용 자체가 바뀝니다.

### 단독 실행 파일(.exe)로 만들기

`build_exe.bat`(윈도우) 또는 `build_exe.sh`(리눅스·맥)를 실행하면 PyInstaller로
묶어 `dist/SmartstoreCollector/` 폴더가 만들어집니다. 폴더 안의 파일이 모두
있어야 실행되므로 옮길 때는 통째로 옮기세요. 만들어진 실행 파일 이름은 원하는
대로 바꿔도 됩니다.

빌드 스크립트는 `PLAYWRIGHT_BROWSERS_PATH=0` 을 걸어 크롬을 사용자 폴더가 아니라
playwright 패키지 안(`.local-browsers`)에 받습니다. 그래야 PyInstaller가 크롬까지
함께 묶어서, **파이썬도 크롬도 없는 PC에서 폴더만 복사해도** 실행됩니다.

이건 선택이 아니라 필수입니다. 묶인 실행 파일에서 Playwright는
`PLAYWRIGHT_BROWSERS_PATH` 를 `0` 으로 고정해 **번들 안만** 찾기 때문에, 크롬을
사용자 폴더에 받아두면 exe가 못 찾습니다.

이미 그렇게 만들어진 exe를 위해 `smartstore_core.py` 에 폴백이 있습니다 — 번들
안이 비어 있으면 사용자 폴더(`ms-playwright`)의 크롬을 자동으로 씁니다.

크롬 경로를 직접 지정하려면 환경변수 `SMARTSTORE_CHROME` 에 크롬 실행 파일
경로를 넣으면 됩니다.

### 명령줄

```bash
python smartstore_cli.py "https://smartstore.naver.com/yes24book/category/da522381ebe945058b0a46c11bd8e5cc" -o 상품명.txt
```

`--max-pages`, `--wait`, `--show` 옵션은 GUI와 같습니다.

## 동작 방식

- 주소의 `cp`(페이지 번호)를 1부터 하나씩 올려가며 방문합니다.
- 각 쪽에서 끝까지 스크롤해 지연 로딩된 상품 카드까지 그려지게 합니다.
- 상품 링크(`/products/숫자`)를 모두 찾아 **상품 ID로 중복을 제거**합니다.
  (상품 하나에 이미지 링크와 제목 링크가 따로 걸려 있어도 한 번만 셉니다.)
- 새 상품이 하나도 없는 쪽을 만나면 마지막 쪽으로 보고 멈춥니다.
- 결과는 윈도우 메모장에서 한글이 깨지지 않도록 BOM 포함 UTF-8로 저장합니다.

## 문제가 생기면

| 증상 | 해결 |
| --- | --- |
| `Playwright가 설치되어 있지 않습니다` | `pip install -r requirements.txt` |
| `Chromium 브라우저를 실행하지 못했습니다` | `playwright install chromium` |
| 상품명을 하나도 못 가져옴 | **브라우저 창 보기**를 켜고 실행해 화면 확인. 네이버가 화면 구조를 바꿨다면 `smartstore_core.py` 의 선택자 조정 필요 |
| 사내망 등으로 `playwright install` 이 막힘 | 환경변수 `SMARTSTORE_CHROME` 에 크롬 실행 파일 경로를 넣으면 그 브라우저를 사용합니다 |

## 참고

네이버가 페이지 구조를 바꾸면 수집이 멈출 수 있습니다. 상품명은 상품 링크
앵커의 텍스트에서 읽으므로 구조 변경에 비교적 둔감하지만, 그래도 결과 개수가
갑자기 0이 되면 위 표의 **브라우저 창 보기**부터 확인하세요.
