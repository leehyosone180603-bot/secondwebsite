# 스마트스토어 상품명 수집기

네이버 스마트스토어 카테고리를 첫 쪽부터 끝까지 넘겨가며 **상품명만** 뽑아
메모장에서 바로 열 수 있는 텍스트 파일로 저장하는 프로그램입니다.

```
체인소 맨 1~23권 세트 / 후지모토 타츠키
원피스 1~110권 세트 / 오다 에이이치로
...
```

가격(`138,000원`), 할인율(`10%`), `무료배송`, 연령 배지(`19`), 리뷰 수 같은
부가 텍스트는 걸러내고 상품명 한 줄씩만 남깁니다.

## 구성

| 파일 | 설명 |
| --- | --- |
| `smartstore_gui.py` | **GUI 프로그램** (창을 띄워 마우스로 조작) |
| `smartstore_cli.py` | 명령줄 버전 (자동화용) |
| `smartstore_core.py` | 수집 로직 (위 두 개가 공통으로 사용) |
| `RUN.bat` | 윈도우에서 더블클릭으로 GUI 실행 (첫 실행 때 준비물 자동 설치) |
| `build_exe.bat` | 윈도우에서 단독 실행 파일(.exe) 만들기 |
| `build_exe.sh` | 리눅스·맥에서 단독 실행 파일 만들기 |
| `requirements.txt` | 필요한 패키지 |

## 설치 (처음 한 번만)

[Python 3.9 이상](https://www.python.org/downloads/)을 설치한 뒤, 명령
프롬프트에서:

```bash
pip install -r requirements.txt
playwright install chromium
```

> 카테고리 페이지는 자바스크립트로 그려지기 때문에, 진짜 브라우저로 화면을
> 띄워 읽어야 상품명이 나옵니다. 그래서 Chromium이 필요합니다.

## 실행

### GUI (권장)

윈도우에서는 `RUN.bat` 을 더블클릭하고, 그 외에는:

```bash
python smartstore_gui.py
```

1. **카테고리 주소**에 수집할 카테고리 URL을 붙여넣습니다.
   (주소에 `?cp=2` 같은 페이지 번호가 붙어 있어도 무시하고 1쪽부터 전체를 훑습니다.)
2. **저장할 파일**을 정합니다. 기본값은 `상품명.txt` 입니다.
3. **[수집 시작]** 을 누릅니다. 진행 상황이 아래 창에 실시간으로 찍힙니다.
4. 끝나면 **[저장한 파일 열기]** 로 메모장에서 바로 확인합니다.

수집 도중 **[중지]** 를 누르면 그때까지 모은 상품명까지만 저장합니다.

옵션:

| 옵션 | 설명 |
| --- | --- |
| 최대 페이지 | 안전장치. 이 페이지 수를 넘으면 멈춥니다 (기본 100) |
| 페이지 간 대기 | 서버에 부담을 주지 않도록 쉬는 시간 (기본 1초) |
| 브라우저 창 보기 | 실제 크롬 창을 띄워 무엇을 읽고 있는지 눈으로 확인 |

### 단독 실행 파일(.exe)로 만들기

`build_exe.bat`(윈도우) 또는 `build_exe.sh`(리눅스·맥)를 실행하면 PyInstaller로
묶어 `dist/SmartstoreCollector/` 폴더가 만들어집니다. 이 폴더를 통째로 복사하면
**파이썬이 설치되지 않은 PC에서도** 실행됩니다. (크롬만 처음 한 번 내려받으면 됨)

만들어진 실행 파일 이름은 원하는 대로 바꿔도 됩니다.

### 명령줄

```bash
python smartstore_cli.py "https://smartstore.naver.com/yes24book/category/da522381ebe945058b0a46c11bd8e5cc" -o 상품명.txt
```

`--max-pages`, `--wait`, `--show` 옵션은 GUI와 같습니다.

## 동작 방식

- 주소의 `cp`(페이지 번호)를 1부터 하나씩 올려가며 방문합니다.
- 각 쪽에서 끝까지 스크롤해 지연 로딩된 상품 카드까지 그려지게 합니다.
- 상품 링크(`/products/숫자`)를 모두 찾아 **상품 ID로 중복을 제거**합니다.
  (상품 하나에 이미지 링크와 제목 링크가 따로 걸려 있어도 한 번만 셉니다.)
- 새 상품이 하나도 없는 쪽을 만나면 마지막 쪽으로 보고 멈춥니다.
- 결과는 윈도우 메모장에서 한글이 깨지지 않도록 BOM 포함 UTF-8로 저장합니다.

## 문제가 생기면

| 증상 | 해결 |
| --- | --- |
| `Playwright가 설치되어 있지 않습니다` | `pip install -r requirements.txt` |
| `Chromium 브라우저를 실행하지 못했습니다` | `playwright install chromium` |
| 상품명을 하나도 못 가져옴 | **브라우저 창 보기**를 켜고 실행해 화면 확인. 네이버가 화면 구조를 바꿨다면 `smartstore_core.py` 의 선택자 조정 필요 |
| 사내망 등으로 `playwright install` 이 막힘 | 환경변수 `SMARTSTORE_CHROME` 에 크롬 실행 파일 경로를 넣으면 그 브라우저를 사용합니다 |

## 참고

네이버가 페이지 구조를 바꾸면 수집이 멈출 수 있습니다. 상품명은 상품 링크
앵커의 텍스트에서 읽으므로 구조 변경에 비교적 둔감하지만, 그래도 결과 개수가
갑자기 0이 되면 위 표의 **브라우저 창 보기**부터 확인하세요.
